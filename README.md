# Acme AI Security & Compliance Assessor

A case-study application for assessing AI use cases against Acme Financial
Services' eight security and AI governance requirements.

## Planned capabilities

- Assess a submitted AI use case against AI-001 through AI-008.
- Connect findings to scenario evidence and policy requirements.
- Identify missing information and recommend actions.
- Display an observable agent execution trace.
- Validate structured results and enforce application guardrails.
